# План переезда

## При переезде сервера
1. Выключить питание
2. Перевезти
3. Включить питание
4. Wi-Fi подключится автоматически (статический IP 192.168.50.15)
5. systemd запустит все сервисы
6. Docker поднимет все контейнеры

## При установке Tesla GPU
1. Вставить карту в сервер
2. Подключить кулер (обязательно!)
3. Подключить EPS питание (не PCIe!)
4. Включить сервер
5. Запустить: `bash /home/evgeniy/gpu_setup.sh`
6. Готово

## Проверка после переезда
```bash
bash /home/evgeniy/migration_checklist.sh
```
